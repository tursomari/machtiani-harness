## Run available validations


Format.

```
gofmt -w path/to/file
```

Build.

```
cd agent && GOCACHE=$(pwd)/.gocache go build ./...
```

Test.

```
cd agent && GOCACHE=$(pwd)/.gocache go test ./...
```

Do not run any `run-live` or `undici` related tests that require network access. Don't go off on a tangent. Run builds and tests as instructed and don't set any timeouts. To run a formatter, run `gofmt -w /path/to/file`.

## Fix any issues

Fix any issue that surface from your validations. Don't not stop trying until format, build, and tests are complete successfully without error.
